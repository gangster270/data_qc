# 로거 센서 구성 대장 (2026-06-08 내려받기 기준)

로거마다 센서 구성이 크게 다르므로, **분석 전에 이 표에서 어떤 변수가 있는지 먼저 확인한다.**

## 3. 발견된 문제와 조치

### 3.1 z6-20400 — TEROS 2조 미연결 (조치 필요)

Port 2·Port 3 의 TEROS 12 두 개가 **관측 전 구간(05-28~06-08) 내내 0.00** 출력
(배지수분·배지온도·EC 6채널 전부). Port 4 만 정상(vwc 30.5~33.0%, 배지온도 21.2~28.6℃).

→ 배선·커넥터·포트 설정 확인 필요. 현재 파이프라인은 이 열을 대표값으로 뽑지 않고
`vwc__rep2`, `soil_temp__rep2` … 로 보존한 뒤 `R04_flatline` 로 "미연결·고장 포트"로 경보한다.

### 3.2 2026-05-14 고온 사건 (데이터 오류 아님 — 실제 사건)

z6-03959 와 z6-07680 에서 **동시에** 발생:

| 로거 | 최고 기온 | 45℃ 초과 지속 | 최고 배지온도 | 최저 습도 |
|---|---|---|---|---|
| z6-03959 | 70.1 ℃ (14:50) | 7.8 시간 | 50.3 ℃ | 15.2 % |
| z6-07680 | 69.7 ℃ (14:30) | 8.0 시간 | 56.6 ℃ | 16.8 % |

전후일 최고기온은 30~34℃. 두 로거가 같은 날 같은 시간대에 동일 패턴을 보이고,
**배지온도까지 함께 상승**했으므로 센서 오류가 아니라 실제 고온(환기 실패·밀폐 추정)이다.

→ 이 때문에 센서 범위 상한을 작물 기준(60℃)이 아니라 **센서 사양(ATMOS 14: 80℃)** 으로
바꿨다. 좁게 잡으면 진짜 사건이 오류로 지워진다. 대신 `R13_heat_event` 규칙을 추가해
기온 45℃·배지온도 40℃ 초과를 경보한다.
**그날 무슨 일이 있었는지 확인이 필요하며, 해당 구간 생육자료 해석에 반드시 반영해야 한다.**

### 3.3 z6-20400 = 야간보광(NI/SL) 처리구

야간 22~04시 PPFD 가 **80.5% 시점에서 5 µmol 초과**, 중앙값 23.5 µmol.
광주기 21.2시간(다른 로거는 10.8~14.2시간). 두 SQ-521 의 야간 값이 23.5 vs 44.2 로
크게 다르다(등기구와의 거리 차) — **주간 차이는 4.8%** 로 작다.

→ ① `qc.night_light_enabled: false` 유지(정상 보광을 오탐하지 않도록).
   ② 이 로거의 PPFD 2조는 **평균내지 말고 개별 유지**(`--replicate keep`). 야간 값이 다른
   것은 센서 오차가 아니라 실제 광환경 차이다.

### 3.4 EC 0 지속 = 센서 고장 아님 (배지 건조)

z6-07680 EC 0 비율 82.6%, z6-03959 32.5%. 확인 결과 **배지수분과 완전히 연동**된다.

| 조건 | EC = 0 비율 |
|---|---|
| vwc < 10 % | 100 % |
| vwc ≥ 20 % | 0 % |

TEROS 12 는 배지가 마르면 포화추출 EC 를 계산하지 못해 0 을 출력한다.
→ `flatline_ignore_zero` 에 `ec` 를 추가해 오탐을 제거했다. 단, z6-07680 의
**배지수분 중앙값 9.68%** 는 그 자체로 건조 상태이므로 관수 관리 확인이 필요하다.

### 3.5 배지수분 단위 (% vs m³/m³)

METER TEROS 는 `% Water Content` 즉 **체적수분 ×100(%)** 로 내보낸다(실측 9~42%).
설정의 배지수분 범위·편차 허용치를 % 기준으로 수정했다(범위 0~75%, 편차 5%,
검증 허용오차 3%). m³/m³ 로 잘못 두면 정상값 전부가 범위 이탈로 잡힌다.

### 3.6 PPFD ↔ 일사량 환산계수는 로거별로 다르다

| 로거 | 주간 PPFD/일사 (µmol·W⁻¹) | 측정 DLI | 일사×2.057 추정 DLI | 배율 |
|---|---|---|---|---|
| z6-03959 | 2.355 | 16.05 | 14.53 | 0.91 |
| z6-20917 | 1.848 | 11.55 | 14.24 | 1.23 |

개방광 이론값은 2.057. 두 로거가 서로 반대 방향으로 벗어나므로 **하나의 계수를 전체에
적용하면 안 된다**(설치 위치·차광·피복 상태 차이). 두 로거 모두 상관은 매우 높다
(r = 0.983, 0.990) — 즉 **로거별 계수를 쓰면 신뢰도 높은 환산이 가능하다.**

→ PPFD 가 없는 **z6-07680** 의 DLI 를 추정하려면, 이 로거가 어느 온실·구역에 있는지에 따라
2.355 또는 1.848 중 어느 쪽을 쓸지 정해야 한다(같은 온실의 로거 계수 사용).

## 4. 로거별 권장 설정

| 로거 | replicate | 비고 |
|---|---|---|
| z6-03959 | `mean`(TEROS 3조가 같은 처리구 반복일 때) 또는 `keep` | 배지온도 편차 1.6~2.1℃ → 위치 차이 확인 필요 |
| z6-07680 | `first` | 단일 TEROS. PPFD 없음 → 일사 환산 계수 지정 필요 |
| z6-20917 | `keep` | TEROS 4조의 배지수분이 27~42% 로 크게 다름 → 서로 다른 위치·처리구로 보임 |
| z6-20400 | `keep` | PPFD 2조는 반드시 개별 유지(보광 위치 차). TEROS 2조 미연결 |
| 7구역-z6-21068 | `first` | 단일 PPFD |

`R10_pair_divergence`(중복 센서 편차) 규칙은 **"동일 조건에 나란히 설치된 센서"** 를 전제한다.
TEROS 반복이 서로 다른 배지·처리구라면 이 규칙은 끄거나(해당 변수 임계값 상향) 무시한다.
현재 z6-20917·z6-03959·z6-20400 에서 뜨는 편차 경보는 대부분 이 경우로 보인다 —
**반복 센서가 같은 위치인지 다른 처리구인지 확인 후 설정을 확정해야 한다.**

## 5. 파일명 규칙 주의

파이프라인은 **첫 밑줄 앞부분**을 로거 ID 로 보고 파일을 묶는다
(`z6-03959_086260946.xlsx` → `z6-03959`). 업로드·복사 과정에서 앞에 해시가 붙으면
(`e0c2ad9b-z603959_...`) 다른 로거로 인식되므로, 저장 시 원래 이름 형식을 유지한다.
